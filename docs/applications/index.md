# Applications

Worked examples: three services built on the framework, each written up as what
it is and what it asked of the framework. The calendar is the framework's own
example and needed no change; the forum and the weather are real services, and
between them they kept the framework honest — nothing in `packages/sextile/` knows
a forum, a calendar or the weather.
